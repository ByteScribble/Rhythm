Buddy — reacting face

A drawn character (not a system emoji) that mirrors each activity state and “speaks” in a bubble. Animations here loop for review; in the app the talk and jump play once on a state change.
Now Calm, focused eyes that glance around; soft smile. Bob 3s loop · look 5s · blink 4s “23 min in. Keep breathing — you’ve got this.”
Completed Happy arc eyes, open smile, rosy cheeks, sparkles. Jump 700ms once, then bob 3s · sparkles 1.4s ×3 “Yoga done! What a lovely start to the day.”
Partial One raised brow, lopsided smile — encouraging. Tilt ±7° 2.4s loop · blink 4s “Some yoga beats no yoga. Proud of you.”
Skipped Relaxed closed eyes, flat mouth, a sleepy “z”. Sway 3.2s loop “Rest is part of the plan too.”
Missed Worried brows, frown, one tear — sad, never angry. Droop 3.2s loop · tear drip 2.2s “Did you complete Yoga? No pressure.”

Construction56×56 viewBox, face circle r25 with 1.5 stroke in status base colour, fill in status soft. Features #172033; stroke 2.2–2.4 at ≥52px, 3–3.5 at ≤36px. PartsAnimate as separate layers: body (wrapper), eyes group (blink), mouth (talk), extras (brow, tear, sparkles, z). Ship as SVG + CSS, or a Lottie/Rive file with five states. TriggersMount / state change → mood swaps with 220ms pop; mouth talks 8 × 180ms while bubble pops in (260ms, 120ms delay). Then idle loop only. Bubblebg/canvas fill, 1px #EEF1F5, radius 16 16 16 4 (tail toward face), 10 14 padding, 14/20 text, max 2 lines, role="status". WhereOne talking buddy per screen (Now card, sheet header or prompt). Small 28px faces in timeline rows are silent — blink only. VoiceWarm, short, never guilt. Missed = gentle question, not blame. Rotate 3–5 lines per state so it doesn’t repeat. AccessFace is aria-hidden; status text and node shape still carry meaning. prefers-reduced-motion → static faces, bubble appears without motion. SettingOffer “Reactions: On / Quiet (no bubble) / Off” in settings for users who prefer a pure, minimal UI.
